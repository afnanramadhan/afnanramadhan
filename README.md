# Hi, I'm Afnan 👋

**Backend development · Automation · Practical software**

I work on Java and Spring Boot services in the banking domain, with a focus on transaction workflows, data processing, and system integrations. Outside work, I build tools that simplify repetitive tasks and explore ideas through hands-on projects.

My interests sit at the intersection of backend engineering and DevOps: building services that are easier to test, operate, and maintain.

## Selected projects

### [Quto](https://github.com/afnanramadhan/quto)
A no-code desktop app for building and running browser automations.

Create step-based workflows, map variables to CSV columns, and run tasks in a visible browser. Includes pause/resume controls, execution logs, and local task persistence.

**Built with:** Electron, React, Playwright, SQLite, Tailwind CSS

### [Finku API](https://github.com/afnanramadhan/finku-api)
A collaborative backend project supporting a personal finance Android application.

The API covers authentication, financial transactions, and integrations, with Swagger documentation and a Google Cloud deployment setup. I participated as a member of the project's Cloud Computing team.

**Built with:** TypeScript, NestJS, Google Cloud Platform

### [BondoMan](https://github.com/afnanramadhan/bondoman-android-app)
A collaborative Android application for managing personal finances.

Features include transaction tracking, receipt scanning, charts, and spreadsheet exports. My contributions included login/logout, background services, broadcast receivers, and financial charts.

**Built with:** Kotlin, Android SDK, Room, Retrofit

- Prefer maintainable solutions over unnecessary complexity.
- Document setup steps, limitations, and technical decisions.
